# Netflix Home Page

A responsive Netflix-inspired landing page built with HTML and CSS. The project recreates the main sections of a streaming service homepage, including a navigation bar, hero banner, email sign-up area, genre selections, trending movie cards, membership benefits, FAQs, and footer links.

## Features

- Netflix-inspired hero section with background image
- Language selector and sign-in button
- Email sign-up call to action
- Genre navigation chips
- Trending movie artwork cards
- "More reasons to join" feature cards
- Expandable FAQ sections using HTML and CSS
- Footer navigation links

## Technologies Used

- HTML5
- CSS3

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sakshi-sonwane/NETFLIX_HOME_PAGE.git
   ```

2. Open `Home_page.html` in a web browser.

No build tools or dependencies are required.
